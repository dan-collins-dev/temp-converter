# How to Run

### Required Tools

- [Go](https://go.dev/)
- [VS Code](https://code.visualstudio.com/) or your preferred IDE

### Steps

Clone the repository and `cd` into the project

```bash
git clone https://github.com/dan-collins-dev/temp-converter.git
cd temp-converter
```

To build and run the program on MacOS and Linux

```bash
go build -o bin/tempconverter
./bin/tempconverter
```

To build and run the program in Powershell

```powershell
go build -o bin/tempconverter.exe
.\bin\tempconverter.exe
```
